# Budget

A simple monthly budget app for your phone: category limits, spending log, recurring bills, savings goals and charts.

Everything you enter is stored only in your phone's browser. Nothing is sent anywhere. Use **Settings → Back up** now and then.

## Install on a phone
Open the site link, then:
- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ → Add to Home screen / Install app

## Run locally
```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```
Then open http://localhost:8080.
